# Flatortee Next-Gen Platform (WIP)

This branch scaffolds the new **Next.js + TypeScript** immersive platform with **Tailwind + shadcn/ui**, motion foundations (**GSAP / ScrollTrigger, Framer Motion, Lenis**) + **R3F** + **Fumadocs**.

## Local dev

```bash
npm install
npm run dev
```

## Static build (GitHub Pages)

```bash
npm run build
```

This repo is configured for **Next.js static export** (`output: 'export'`) and a Pages deploy workflow that publishes the `out/` directory.
